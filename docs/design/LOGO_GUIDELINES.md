Future production work must preserve aperture geometry/gap, document actual licensed lettering, check genuine small-size outputs and create only necessary vector/monochrome/transparent exports. Record real usage rights; visual approval is not trademark clearance, registration or a repository reuse license. Do not invent those results or select a replacement logo without an owner request.
