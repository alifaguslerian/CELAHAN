# W3 3D pet interaction — November 2, 2026

Status: Historical technical checks. The owner rejected this mesh appearance, motion and inline navigation; DEC-57 supersedes it. Renderer/model/viewer code and obsolete tests/dependencies have been removed. See [current correction](2026-11-02-w3-pet-motion-correction.md). W4 and publication remain gated.

## Authorization and delivered behavior

The owner requested animated, rotatable package mascots and a selection transition in which the pet enlarges on the left before its information appears on the right. In the follow-up the owner explicitly chose **new 360-degree models**, acknowledging that shape/details require reconstruction from the existing two-dimensional references. [DEC-56](../planning/DECISIONS.md) supersedes the earlier immediate-detail-navigation requirement for normal homepage activation. It does not replace or regenerate the approved hero or source images.

The four procedural meshes retain the sand lens/olive motif, sage shield/keyhole, mineral crescent/connector and low terracotta map/compass identities. They have actual volume and backs, separate eyes and small movable arms. They are newly authored interpretations, not exact conversions or owner-approved final geometry. Existing WebP artwork remains the loading/no-JavaScript/WebGL failure fallback and compact selector artwork.

Normal homepage activation expands the selected model in place, preserving its canvas and displaying the shared qualitative content on the right. The shared-element transition takes 420 ms, followed by a 200 ms information reveal after a 260 ms delay. A visible return control restores focus to the originating link. Compact selectors change the active package; full details and consultation remain ordinary allowlisted links. Modified activation and JavaScript-disabled browsing use native detail destinations. Package selection is transient component state and is not transmitted, stored or added to URL parameters.

The selected model supports unrestricted horizontal rotation through drag, arrow keys and labeled rotate buttons, plus front-view reset. Vertical page scrolling remains available on touch screens. Hover/focus produces a finite 900 ms eye/arm/body greeting; selected-model pointer movement gently shifts the eyes. Idle models do not run an animation loop. Reduced motion disables spatial expansion, greeting and eye tracking; explicit rotation still works. Unsupported view transitions use the same immediate layout with a short information entrance. The detail pages use the same viewer.

## Limits

Browser checks use desktop Chromium and emulated mobile input/viewports. Physical-device GPU behavior, screen readers, native browser zoom, Firefox/WebKit and deployed cache/field performance are not certified. The 3D model geometry, proportions, back designs and timing remain subject to owner visual review. The original raster fallback is intentionally more detailed than this newly modeled geometry. Phones retain natural scrolling for selected-model information. Unsupported or lost WebGL falls back to ordinary content and artwork; model access is never required to understand a package or reach consultation.
